## 글 올리는 방법

1. GitHub 저장소의 `posts/` 폴더에 `파일이름.md` 를 올립니다. (파일 이름이 글 주소가 됩니다)
2. 파일 맨 위에 아래처럼 정보를 적습니다.
3. 1~2분 뒤 블로그 목록에 자동으로 나타납니다.

```
---
title: 글 제목
date: 2026-10-21
author: kilkat
tags: Web, Pwnable
summary: 목록에 보일 한 줄 요약 (생략하면 본문 앞부분을 사용)
---
본문은 마크다운으로 작성합니다.
```

## 쓸 수 있는 문법

- **굵게**, *기울임*, `인라인 코드`, [링크](https://ctftime.org)
- 코드 블록, 인용, 표, 이미지(`![설명](images/그림.png)`)

> 초안은 front matter 에 `draft: true` 를 넣으면 목록에서 제외됩니다.

| 분야 | 예시 |
|---|---|
| Pwnable | 힙 익스플로잇 분석 |
| Web | 인증 우회 취약점 분석 |
